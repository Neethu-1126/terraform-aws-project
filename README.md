# Terraform AWS S3 Project

## Overview

This project demonstrates how to use Terraform to provision and manage AWS S3 buckets using Infrastructure as Code (IaC).

## AWS Service Used

- Amazon S3

## Terraform Concepts Practiced

- AWS provider configuration
- Terraform resources
- Input variables
- `terraform.tfvars`
- Terraform outputs
- Terraform state
- `terraform plan`
- `terraform apply`
- `terraform destroy`
- `count` for creating multiple resources
- Terraform `.gitignore` best practices
